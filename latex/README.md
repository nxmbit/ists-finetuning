# Dokumentacja w LaTeX

Wymagana jest dystrybucja LaTeX z `latexmk`, `pdflatex` oraz pakietami używanymi w `main.tex`, w tym polskim językiem Babel.

W katalogu `latex` uruchom `make`. Gotowy dokument znajduje się w `output/main.pdf` i jest śledzony przez Git. Polecenie `make clean` usuwa pliki pośrednie z katalogu `build`.
